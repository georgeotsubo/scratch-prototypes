Tab bar .pl-tab-bar · 1495:394

Icons are #pl-tab-home / -search / -bookings / -profile from the sprite, at the 25px size Figma uses. Figma applies a GLASS effect to the bar; there's no CSS equivalent, so this is a solid surface/default pill with the drop shadow.

Icons .pl-icon · Figma page "iOS icons"

Injected as an inline SVG sprite by icons.js — external <use href="file.svg#id"> is blocked on file://, and these prototypes get opened directly as often as they get served. Monochrome icons are currentColor, so they take the colour of whatever they sit in. The three stars and map-pin are vector paths that are two-tone by design, painting fixed colours (icon/rating / icon/disabled / icon/red + white) directly instead of currentColor. Each sprite id is #pl- + the name below. Multi-colour marks (e.g. Google) live in assets/ and are referenced with <img>.
